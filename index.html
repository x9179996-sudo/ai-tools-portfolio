步驟二：貼到 GitHub 的 tools.json

1. 前往你的 GitHub repo，點開 tools.json

2. 點右上角鉛筆圖示（Edit this file）

3. 找到 "tools": [ 這一行，在第一個 { 前面貼上你剛複製的內容，後面加一個逗號 ,

4. 點「Commit changes」→「Commit changes」儲存

5. 等 1-2 分鐘後重新整理作品集頁面，新工具就會出現
